## 1.0.0

Initial release.

### Added

- MkDocs site with Material for MkDocs, a custom landing page, dark and light themes and full-text search.
- Documentation covering getting started, writing, automation, development and resources.
- `docs-validation.yml`: markdownlint, strict build and lychee link checking with an aggregated result job.
- `pr-quality.yml`: configuration validation, workflow security rules and pull request description check.
- `deploy-docs.yml`: build and publish to GitHub Pages with the official actions.
- Issue forms for bug reports and documentation requests, and a pull request template.
- `scripts/check_config.py` for navigation, YAML and workflow security validation.
