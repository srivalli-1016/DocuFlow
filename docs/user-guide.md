# User Guide

## Getting Started

Follow the [installation guide](installation.md) to set up the project.

## Basic Usage

1. Register an account and log in.
2. Navigate to the voter dashboard.
3. View the available elections and candidates.
4. Select an election and cast your vote.
5. The system records the submitted vote.
6. View election results when they are made available.
7. Administrators can manage elections and candidates.
