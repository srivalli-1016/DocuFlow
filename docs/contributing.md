# Contribution Guidelines

Thank you for your interest in contributing to Smart Voting System.

## Getting Started

1. Fork the repository and clone your fork.
2. Install the project by following the installation guide.
3. Create a branch for your change.

## Making Changes

- Keep each pull request focused on a single change.
- Follow the existing code style and naming conventions.
- Add or update tests and documentation when behaviour changes.

## Commit Messages

Write short, descriptive commit messages in the imperative mood, for example `Add search to the project list`.

## Pull Requests

1. Push your branch to your fork.
2. Open a pull request against the default branch.
3. Describe what changed and why.
4. Wait for the automated checks to pass and for a maintainer review.

## Reporting Issues

Open an issue with clear steps to reproduce the problem, the expected result and the actual result.
